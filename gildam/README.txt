길담 — 간단한 전국 쓰레기통 지도

dist 폴더 안의 index.html을 브라우저로 열면 됩니다. 인터넷 연결이 필요합니다.
dist 폴더를 Vercel에 배포해도 됩니다. 빌드 명령과 API 키는 필요하지 않습니다.
정확한 현재 위치 기능은 HTTPS 배포 또는 localhost에서 사용하세요.

구성: index.html(화면), style.css(디자인), app.js(기능), bins.js(공개 위치 데이터).
기능: 전국 지도, 17개 시도 중심 이동, 등록된 이름·주소 검색, 내 위치,
지도 클릭 출발지 선택, 직선거리순 목록, 카카오맵 외부 도보 길찾기.
출발지가 없으면 카카오맵에서 출발지와 도보를 선택하세요.

데이터: OpenStreetMap에 등록된 대한민국 amenity=waste_basket 위치.
2026-11-27 수집한 실제 위치 3,563곳을 bins.js에 포함했습니다.
원본 지도 데이터 기준: 2026-11-24. 자동 갱신이 아닌 수집본입니다.
실내로 표시된 곳과 접근 제한으로 표시된 곳은 제외합니다.
표시가 없는 실제 실내·제한 장소나 철거된 위치가 포함될 가능성이 있습니다.
전국 모든 쓰레기통을 포함하지 않으며, 예시 위치를 만들지 않습니다.
